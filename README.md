# Dashboard

A personal dashboard desktop app built with Electron + Flask. Displays a live clock, AI chat assistant, Google Calendar, Google Tasks, notes, a daily morning brief, investment research, and Canvas LMS integration.

## Features

- **Clock** — live time and date display
- **AI Assistant** — local LLM chat via Ollama with tool use:
  - Web search (Tavily)
  - Google Calendar — list, create, delete events
  - Gmail — save draft emails
- **Calendar** — upcoming events for the next two weeks via Google Calendar
- **Tasks** — Google Tasks integration with due dates
- **Notes** — freeform local notepad
- **Morning Brief** — daily summary generated by the LLM covering emails, calendar, markets, and portfolio holdings; saved to `flask_app/data/morning_brief.md`
- **Investment Research** — AI-powered research assistant with:
  - Persistent sessions with auto-generated titles and summaries
  - Pinboard for saving key findings
  - Tool use: live stock quotes, news search, portfolio data, local file reading
  - Portfolio Review mode with market context
- **Canvas** — Canvas LMS integration with:
  - Course and assignment listing with caching
  - Sync Canvas assignments to Google Calendar
  - AI chat assistant for Canvas-specific queries
  - Persistent sessions with summaries

## Tech Stack

| Layer | Technology |
|---|---|
| Desktop shell | Electron |
| Backend | Flask (Python) |
| LLM | Ollama (default: `qwen3.5:latest`) |
| Web search | Tavily |
| Google APIs | Calendar, Gmail, Tasks |
| Market data | yfinance |
| Canvas | Canvas LMS REST API |

## Prerequisites

- [Node.js](https://nodejs.org/) and npm
- Python 3.11+
- [Ollama](https://ollama.com/) running locally with your chosen model pulled

## Setup

**1. Clone and install Node dependencies**
```bash
git clone <repo-url>
cd Dashboard
npm install
```

**2. Create the Python virtual environment**
```bash
cd flask_app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**3. Configure environment variables**

Copy `.env.example` to `.env` (or create `.env` in the project root):
```
GOOGLE_CLIENT_ID=your_google_oauth_client_id
GOOGLE_API_KEY=your_google_api_key
TAVILY_API_KEY=your_tavily_api_key
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen3.5:latest

# Optional: Investment Research
PORTFOLIO_DB_PATH=/path/to/portfolio.db

# Optional: Canvas LMS
CANVAS_BASE_URL=https://your-institution.instructure.com
CANVAS_KEY=your_canvas_api_key
```

**4. Google OAuth setup**

In the [Google Cloud Console](https://console.cloud.google.com/):
- Enable the **Gmail API**, **Google Calendar API**, and **Google Tasks API**
- Create an OAuth 2.0 client (Web application)
- Add `http://localhost:8001` to Authorised JavaScript origins
- Add `http://localhost:8001/api/brief/oauth/callback` to Authorised redirect URIs
- Download `client_secret.json` and place it in `flask_app/data/`

**5. Run**
```bash
npm start
```

Electron will start Flask on port 8001 and open the app window automatically.

## Morning Brief

The brief is generated by running:
```bash
python scripts/morning_brief.py
```

Or click **Generate Now** in the Morning Brief tab. Requires Gmail connected via the Morning Brief tab (OAuth flow).
